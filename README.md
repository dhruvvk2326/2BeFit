# Fitness Web Application

This README provides instructions and details for the Fitness Web Application. This app is built using Next.js, TypeScript, Node.js, MongoDB, RapidAPI, and Twilio, and it features advanced exercise search functionality with secure authentication.

1. Login Page
Description: Entry point for users to securely log in or sign up.
Key Components:
Input fields for email and password.
Option for new user registration.
![Alt text](photos\signup.png)
2. Home Page
Description: A dashboard where users can explore exercises tailored to their needs.
Key Components:
Dropdown or grid to select:
Body Parts: E.g., Chest, Arms, Legs.
Equipment: E.g., Dumbbells, Machines, Resistance Bands.
Search bar for querying exercises by name.
![Alt text](photos\homepage1.png)
![Alt text](photos\homepage2.png)
3. Detail Page
Detailed exercise card that displays:
Exercise GIF for visual guidance.
Exercise name and description.
Muscles targeted and body parts involved.
![Alt text](photos\ddetailpage1.png)
4. Related Exercises
Section for related exercises:
Suggested exercises based on the user's selection.
Direct links to YouTube tutorials for the selected exercise.
![Alt text](photos\detailpage2.png)
